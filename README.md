# Portfolio Website

A single-page professional portfolio built with HTML, CSS, and JavaScript. Designed to showcase profile, experience, skills, and contact information in a clean, responsive layout.

## Features

- Responsive navigation with mobile menu
- Hero, about, clients, experience, skills, education, and contact sections
- Resume download
- Local fonts and assets (no external CDN dependencies)
- Bootstrap-based layout with custom styling
- Smooth scrolling and interactive UI elements

## Project Structure

```
├── index.html              # Main page
├── assets/
│   ├── css/                # Stylesheets
│   ├── js/                 # Scripts
│   ├── fonts/              # Web fonts
│   ├── icons/              # Favicon
│   ├── images/             # Image assets
│   └── resume/             # Resume PDF
└── README.md
```

## Run Locally

Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/abhijeetsinghdevgan/uzma-hassan-portfolio.git
cd uzma-hassan-portfolio
```

Or serve the folder with any static file server for local development.
